# Altru Robotics

Altru Robotics builds intelligent robotics systems for real-world autonomy, operator control, embedded hardware, and human-facing robot experiences.

Our core platform is **AptOS**: a modular robotics workspace that brings together mobile apps, robot adapters, runtime services, embedded tooling, and maintained hardware-driver mirrors.

## Focus

- Robot runtime orchestration and control surfaces
- Android-first operator and companion applications
- Embedded hardware tooling for Arduino, ESP32, and robotics peripherals
- ROS 2 integration for mapping, navigation, sensing, and device bridges
- Practical AI-assisted development workflows for robotics systems

## Active Repositories

- **AptOS** - Core workspace for applications, runtime services, docs, and system orchestration
- **AptOS-Adapter** - Robot adapter workspace split from the legacy ROS setup
- **Apt_Embedding_System** - Embedded hardware tooling and agent-ready device workflows
- **mpu6050_driver** - AptOS-maintained MPU6050 ROS 2 driver mirror
- **sllidar_ros2** - AptOS-maintained SL LIDAR ROS 2 driver mirror

## Repository Policy

Active engineering repositories are private by default. Archived repositories are retained for traceability, migration history, and historical reference.
