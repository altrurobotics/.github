# Contributing

Altru Robotics uses focused, reviewable changes.

## Standards

- Keep changes scoped to one system or behavior.
- Prefer clear commit messages that explain the intent.
- Do not mix large formatting changes with functional changes.
- Document migration or setup changes in the relevant README.
- Treat robot safety, credentials, and operator control paths as high-risk areas.

## Review Expectations

Pull requests should describe:

- What changed
- Why it changed
- How it was tested
- Any deployment or hardware assumptions

Archived repositories are read-only unless explicitly restored for migration work.
