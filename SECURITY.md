# Security Policy

Altru Robotics repositories are private by default and may contain robotics integration details, internal workflows, or device-specific configuration.

If you discover a security issue, do not open a public issue. Contact the organization owner directly with:

- A concise summary of the issue
- Affected repository or component
- Steps to reproduce when safe
- Potential impact

We will triage reports according to impact on robot safety, operator control, credentials, and deployment integrity.
